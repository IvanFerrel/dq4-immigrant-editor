# Changelog

## 1.0.0 – 2026-11-25
First public release.

- Edit the 24 received immigrants and your own immigrant.
- Unique IDs generated automatically.
- 3-line messages (15 characters per line) padded like the game.
- 24 ready-made character templates.
- Share codes (`DQ4I1:`) to pass immigrants between saves.
- Out-of-range values that freeze the game are blocked on save.
- Save checksum recalculated automatically.
- Sprites read from the user's own ROM (no game graphics included).
- English, Spanish and French versions; hobby names taken from the game.
